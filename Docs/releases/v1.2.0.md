# Screen Off 1.2.0

Screen Off now speaks English and Japanese, and the interface has been trimmed wherever it was saying
more than it needed to.

- **Three languages.** English, 简体中文 and 日本語, chosen in Settings → General. Each is listed in
  its own script, so you never have to read the current interface language to find your own.
  Switching takes effect after a restart, and that restart goes through the normal quit path, so
  brightness, input lock and the lid setting are all restored before the app relaunches.

- **Permissions only show up when something is actually missing.** The General tab used to list all
  three permissions permanently, each with a paragraph of explanation. It now lists a permission only
  when the feature that needs it is in use and the permission is not in place: Input Monitoring while
  automatic screen off is on, the background daemon while keep-awake-with-lid-closed is on. A
  permission that nothing currently needs is a normal state, not a to-do item. When nothing is
  pending, a single line confirms that everything required is granted, with the individual states in
  its tooltip. Accessibility is the one exception and is judged on the permission alone, because Lock
  Input has no switch and macOS shows its authorization prompt only once.

- **Setting a shortcut is one gesture again.** Clicking a recorder clears the current shortcut and
  waits for a new one; pressing Esc or clicking elsewhere leaves it unset. Changing and removing a
  shortcut are the same action, so the separate clear button next to the field is gone.

- **Menu bar.** Remote Mode and Lock Input lead as the two mode buttons. The display moved underneath
  as a labelled toggle, because an action label next to a switch reads ambiguously — "on" would name
  neither the screen nor the feature. Settings no longer carries an ellipsis: it opens a window
  rather than asking for anything further.

- **Settings.** Remote is now the first tab, since that is what this Mac is mostly set up for. Each
  tab takes its own height instead of a shared one, so About no longer leaves a large empty area
  while General is squeezed into a scroll view.

Nothing about the capability boundaries changed. Keep-awake-with-lid-closed still writes the
system-level `SleepDisabled` through the signed privileged daemon, is still offered only on AC power,
and is still released when the power is unplugged, on quit, and whenever the daemon loses its last
client.
