# Screen Off 1.0.0

The stable starting point for Screen Off's open-source repository.

- Keep your Mac awake while the built-in display and keyboard backlight stay dark.
- Turn the screen off from the menu bar, with a customizable shortcut, or after an idle period.
- Restore the previous brightness when local input returns.
- Automatically choose between GitHub and the FrameFlow update server, with signed updates and connection fallback.
- Install with a company-signed, Apple-notarized drag-to-install DMG.

Requires macOS 14 or later and an Apple Silicon MacBook. Automatic screen off uses Input Monitoring.

Existing installations can upgrade normally. When upgrading from 0.1.1 or earlier, grant Input
Monitoring again and check Launch at Login because those previews used a different app identifier.
If GitHub is unreachable, download the installer from
[FrameFlow](https://frameflowtech.com/updates/screenoff/v1.0.0/ScreenOff.dmg).
