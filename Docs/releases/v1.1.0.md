# Screen Off 1.1.0

The menu bar is rebuilt around two instant actions and two ongoing states, and two new features join it.

- Turn off the screen and lock local input side by side; remote mode and keep-awake are switches
  underneath, with automatic screen off and its idle slider in their own group.
- **Lock input** stops the built-in keyboard and trackpad and dims the screen with them. Hold
  Fn + Delete for one second to unlock. The on-screen hint can be switched off in Settings.
- **Keep awake with the lid closed** writes the system sleep setting through a signed helper, and is
  offered only on AC power. It reverts when the power is unplugged, when the app quits, and even if
  the app is force-quit.
- Settings now shows the authorization state for both Input Monitoring and Accessibility.

Requires macOS 14 or later and an Apple Silicon MacBook. Lock input needs Accessibility. Keeping the
Mac awake with the lid closed needs a one-time approval under Login Items & Extensions.

There is still no analytics SDK and no telemetry of its own. If you allow it, the daily update check
carries an anonymous system profile — macOS version, Mac model, CPU, memory and language — so the
project can tell which versions still need support. It contains no identifier, Sparkle asks before it
is ever sent, and Settings → General can turn it off at any time.

Existing installations upgrade normally. If GitHub is unreachable, download the installer from
[FrameFlow](https://frameflowtech.com/updates/screenoff/v1.1.0/ScreenOff.dmg).
