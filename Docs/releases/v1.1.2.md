# Screen Off 1.1.2

A real restore bug, and a rebuilt permissions section.

- **Stage Manager now really comes back.** When it had never been switched on before a remote-mode
  session, the snapshot recorded "no preference key". Restoring that state only deleted the key —
  which does not make WindowManager leave Stage Manager, so it kept running and later wrote its own
  state back. An absent key means off, so the restore now writes `false` explicitly.
- Remote mode logs every step of capture, apply and restore, so a restore that does not take effect
  can be diagnosed from the log instead of guesswork.
- The permissions section is rebuilt. Each entry now uses the name macOS itself uses — Input
  Monitoring, Accessibility, background daemon — states what the permission is for in one line, and
  shows the current status with an icon. Approval happens in System Settings, so the status is now
  re-read whenever the window comes back to the front; it used to stay on "not granted" until the
  window was reopened.

Requires macOS 14 or later and an Apple Silicon MacBook.
