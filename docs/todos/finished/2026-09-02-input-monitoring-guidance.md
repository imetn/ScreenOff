# 已完成 · 2026-09-02 输入监控授权闭环与空闲轮询收敛

代码已落地，真机验证仍列在 [待办](../README.md) 高优先。

- 「输入监控」授权改为按需申请：只在首次打开「自动关闭屏幕」时弹窗，或启动时已开启该开关；从未开启过的用户不再在每次启动时被打扰。
- 授权后无需重启：打开菜单、打开设置以及自动关屏轮询的每一轮都会重试 `IOHIDManager` 订阅，接回后立即切换为可区分远程输入的主路径。
- 未授权或已拒绝时，菜单栏状态行与设置「功能」页明示原因，并提供跳转系统设置「输入监控」的入口。
- 空闲到点却进不了会话（读亮度失败、内建屏离线）时改为 10 秒退避重试，不再 0.5 秒空转并刷日志。
- 暗屏会话中若 HID 路径可靠，不再保留 5 秒空轮询，唤醒完全由回调完成。
- 清理未使用的 `canControl`、`heldKinds`、`isHolding`，睡眠通知 observer 在退出时移除。
- `AppPresentationController` 不再记录具体窗口身份：任一带标题普通窗口关闭后按剩余可见窗口决定是否恢复 `.accessory`。

待真机确认：首次开启自动关屏是否只弹一次系统授权；授权后不重启是否即可接回 HID；拒绝后「前往系统设置」是否定位到输入监控页。
