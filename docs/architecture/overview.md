# 架构总览

## 运行形态

Screen Off 是单进程菜单栏 App；只有合盖保持唤醒需要额外的特权 Helper。

```text
MenuBarExtra / Settings
          │
       App State
          │
 ┌────────┼─────────┬─────────┬──────────┐
 电源断言  物理输入   屏幕亮度   键盘背光   合盖 Helper
  IOKit    IOHID     Display   Core       XPC + pmset
                     Services  Brightness
```

## 状态所有权

- 用户偏好：App 级状态，持久化到 `UserDefaults`。
- 当前屏幕与键盘原始亮度：仅在一次无光会话期间保存在内存中。
- IOKit 电源断言 ID：由电源服务持有，关闭功能和退出时释放。
- 合盖状态：由 Helper 以短期租约管理，租约失效后恢复系统默认值。
- 菜单栏与设置窗口共享同一 App 级模型，不各自复制状态。

## 组件边界

- `Views` 只呈现状态和发送用户意图，不直接调用系统 API。
- `Models` 保存偏好与可呈现状态，不持有特权逻辑。
- 后续 `Services` 分别封装电源、输入、屏幕、键盘和登录项能力。
- 特权 Helper 只允许切换固定的合盖睡眠策略，不执行任意命令。

## 数据

项目没有数据库、网络服务或云端数据。持久化数据仅包含用户开关和空闲时长。
