# 系统能力与安全边界

## 能力矩阵

| 能力 | 预定机制 | 权限与分发 | 失败策略 |
|---|---|---|---|
| 阻止空闲睡眠 | IOKit `PreventUserIdleSystemSleep` | 公共 API | 释放断言并回到系统默认 |
| 登录时启动 | `SMAppService.mainApp` | 公共 API、用户批准 | 保持关闭并显示原因 |
| 识别物理输入 | `IOHIDManager` | 以真实设备验证权限表现 | 不自动恢复，保留手动恢复入口 |
| 内建屏幕亮度 | 动态解析 `DisplayServices` | 私有接口、直接分发 | 禁用暗屏功能，不影响唤醒功能 |
| 键盘背光 | 动态解析 `CoreBrightness` | 私有接口、直接分发 | 单独禁用，不影响屏幕控制 |
| 合盖保持唤醒 | 签名 Helper + XPC + `pmset disablesleep` | 管理员批准、不可进沙盒 | 租约超时后强制恢复默认 |

## 强制安全规则

- 不允许 App 通过 Helper 执行任意 shell 命令。
- Helper 只接受启用、续租、停用和查询四类固定请求。
- 启用合盖模式后，App 每 30 秒续租；90 秒没有续租时 Helper 自动执行恢复。
- 拔掉电源时 App 立即停用合盖模式；Helper 同样独立检查租约，避免依赖 UI 进程存活。
- 屏幕与键盘亮度修改前必须读取原值；读取失败则不写入。
- 私有符号缺失时功能不可用，不尝试猜测其他选择器或内存布局。

## 分发结论

首版使用 Developer ID 签名、公证和 DMG 直接分发。Mac App Store 版本不在首版范围内，因为合盖 Helper、内建亮度和键盘背光能力不符合当前沙盒边界。
