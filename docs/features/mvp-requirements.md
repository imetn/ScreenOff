# Screen Off MVP 需求

## 1. 产品目标

当 MacBook 作为远程控制主机长期在线时，减少内建屏幕和键盘背光的无效点亮，同时提供可靠、可恢复的保持唤醒能力。

## 2. 支持范围

- Apple Silicon MacBook。
- macOS 14 及以上。
- 内建屏幕与内建键盘。
- Developer ID 签名、公证后直接分发。

## 3. 菜单栏快捷窗口

- 显示当前运行状态。
- 提供“立即关闭屏幕”操作。
- 提供“保持电脑唤醒”开关。
- 提供“合盖后保持唤醒”开关。
- 提供“自动关闭屏幕”开关与空闲时长选择。
- 提供“同时关闭键盘背光”开关。
- 提供设置入口和退出操作。

## 4. 设置窗口

设置窗口参考原生 macOS 偏好设置，顶部使用三个标签：

- 功能：普通保持唤醒、合盖保持唤醒、自动关闭屏幕、10 秒至 4 小时时长、同步关闭键盘背光。
- 通用：登录时启动、自动检查更新。
- 关于：App 图标、版本、开源状态、GitHub 入口和手动检查更新。
- 设置窗口打开时显示 Dock 图标；关闭最后一个设置窗口后恢复为纯菜单栏 App。

## 5. 行为规则

### 5.1 普通保持唤醒

- 开启后阻止因空闲导致的系统睡眠。
- 不阻止用户主动睡眠、低电量保护或合盖睡眠。
- 关闭功能或退出 App 时释放全部电源断言。

### 5.2 合盖保持唤醒

- 开启时自动开启普通保持唤醒。
- 首版仅在接通电源时生效。
- 拔掉电源、关闭开关或退出 App 后恢复系统默认睡眠行为。
- 不安装特权 Helper；能力边界服从 macOS 对 `PreventSystemSleep` 的系统限制。

### 5.3 自动关闭屏幕

- 空闲计时只以物理键盘、鼠标和触控板输入为准。
- UU 远程、系统屏幕共享及其他软件注入事件不得重置本地空闲计时或恢复亮度。
- 到时后保存当前内建屏幕亮度，再将硬件亮度降至最低。
- 物理输入、关闭功能或退出 App 时恢复之前保存的亮度。
- “立即关闭屏幕”复用同一保存与恢复逻辑。

### 5.4 键盘背光

- 启用后与自动关闭屏幕及“立即关闭屏幕”同步执行。
- 暗屏时保存当前键盘背光亮度并降至零。
- 恢复屏幕时恢复之前保存的键盘背光亮度。
- 不支持背光的设备不得报错或阻断其他功能。

### 5.5 登录启动

- 用户主动开启后，通过系统登录项启动 Screen Off。
- 启动后只显示菜单栏图标，不自动弹出窗口。

### 5.6 应用内更新

- 使用 Sparkle 2 更新 Developer ID 直接分发的 App，不要求用户手动替换应用。
- 更新包必须同时经过 Developer ID 签名、Apple 公证与 Sparkle EdDSA 验证。
- Appcast 与更新包必须使用 HTTPS；私钥只保存在发布者钥匙串或 CI 密钥中。
- GitHub 仓库、问题反馈、Appcast 或公钥尚未配置时，界面必须明确显示不可用，不启动错误配置的更新器。

## 6. 状态与错误

- 菜单栏图标至少区分正常、保持唤醒和无光运行状态。
- 系统能力缺失、更新源未配置或权限被拒绝时，在菜单栏窗口或设置中显示明确原因。
- 任何失败都不得留下无法恢复的亮度或睡眠设置。

## 7. 非功能要求

- 无账号、无分析统计；仅在用户检查更新或允许自动检查时访问配置的 Appcast。
- 不读取或保存输入内容、屏幕内容和远程会话内容。
- 菜单栏空闲状态不进行高频轮询。
- 系统状态修改必须幂等，并可通过手动命令恢复。

## 8. 首版不做

- 外接显示器及 DDC 控制。
- Intel Mac。
- 针对具体远程控制软件的插件或进程识别。
- 定时计划、配置方案、云同步、远程开关和使用统计。
- Mac App Store 分发。

## 9. 验收标准

- 普通保持唤醒可通过 `pmset -g assertions` 观察到，并在关闭后消失。
- UU 远程持续操作时，本地屏幕和键盘保持无光；物理输入能恢复原亮度。
- 合盖后远程连接持续可用；拔掉电源后恢复系统默认睡眠策略。
- App 正常退出、异常终止和重新启动后，不遗留错误的系统状态。
- 登录后 App 自动出现于菜单栏，不显示 Dock 图标。
- 打开设置后 Dock 显示 Screen Off 图标，关闭设置后 Dock 图标消失且菜单栏进程继续运行。
